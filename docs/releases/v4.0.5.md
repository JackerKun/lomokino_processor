LomoKino Studio 4.0.5 修复了启动时检查更新可能导致的闪退。

- 启动时的 GitHub 更新检查移到独立进程。断网、请求超时或更新进程异常退出时，主窗口仍可继续使用。
- 「帮助 → 检查更新」仍支持手动查询。排查启动问题时，可用 `LomoKinoGUI.exe --no-update-check` 跳过本次自动检查。
- 可在 Assets 中选择 Windows x64、macOS Apple Silicon 或 macOS Intel 下载包。Windows 请完整解压后打开 `LomoKinoGUI.exe`。

[查看 v4.0.4 到 v4.0.5 的代码变更](https://github.com/JackerKun/lomokino_processor/compare/v4.0.4...v4.0.5)
