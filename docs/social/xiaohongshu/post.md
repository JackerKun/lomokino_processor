# 发布标题

LomoKino 扫成长条，自动切成视频

## 可直接发布的正文

玩 LomoKino 最费时间的，往往不是拍，而是拍完以后。

扫描仪扫出来是一张张长条。以前要自己一格一格切图，再把画格按顺序拼成视频。拍的时候很开心，整理起来却很磨人。

所以我做了 LomoKino Studio 🎞️

流程很直接：
① 先用扫描仪把胶片扫成长条，不用提前逐格裁开。
② 把扫描好的长条导入软件，自动识别分隔带、裁切出画格。
③ 确认顺序和播放帧率，导出 MP4，胶片里的动作就能重新播放。

遇到暗场或不规则边界，也能拖动裁切框、输入像素坐标微调。残帧可以排除，缩略图可以拖动排序。改好的结果会直接用于导出。

想继续后期，也能输出 PNG 图片序列。整个过程在本机完成，不用上传照片、不用注册账号。

软件负责处理扫描好的图片，不直接控制扫描仪。自动识别也不是所有扫描条件下都完美，导出前看一遍会更稳妥。

📷 本次配图使用无人物合成素材：黑白山水和无人模型帆船，参考真实长条扫描的黑带、窄边与颗粒质感，全部是虚构示例。界面是真实软件截图，没有使用测试照片中的人物。

3. 识别：自动分隔带与识别设置。
4. 序列：查看画格、确认播放顺序。
5. 导出：MP4 / PNG。
6. 上手：内置无人物示例，共 1 张长条 / 8 帧。
