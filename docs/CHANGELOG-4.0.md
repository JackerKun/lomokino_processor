# 4.0.0 — 扫描、校对、导出统一工作流

- GUI 拆分为素材 / 原图 / 属性与确认帧序列；统一深色主题与系统浅色模式兼容。
- QGraphicsScene 使用原图像素，长图下采样预览独立映射 X/Y，解决缩放和取整导致的位置漂移。
- 八方向拖框、整数坐标、手动加框、复制、删除、包含开关、复查标记、30 步撤销重做。
- 深浅分隔带自适应、保守齿孔证据、避免固定左右裁切，长扫描条不按整图高度丢帧。
- 显式等距模式与 ±6° 可选纠偏；低证据与不规则帧提醒人工检查。
- 统一 GUI / CLI 导出：当前坐标、排除与排序直接输出；修复生成视频重新识别覆盖编辑的问题。
- PNG 支持 16 位整数；图片清单可追踪坐标和处理选项；工程相对路径与缺失源重定位。
- H.264 / FFmpeg 与 mp4v 真实区分；FPS 参数生效，输出不拉伸，临时文件与取消保护，视频读回复核。
- 打包包含 FFmpeg；新增无界面编码自检；macOS ARM64 / Intel、Windows x64 CI。
- 九张 demo 共 44 帧数量核对，25 项回归测试；真实 macOS 应用截图与中英说明。

当前没有逐帧稳像、彩色负片色罩还原、音轨、插帧或英文 GUI；自动候选仍需人工复查。
